# 音频文件夹管理

管理 Lyrico 扫描的音乐文件夹，以及音乐库的维护操作。

## 文件夹管理

进入路径：`设置` → `音乐库管理` → `音频文件夹`。

文件夹管理页包含"文件夹"和"歌曲"两个标签页，分别用于查看文件夹树结构和该范围下的歌曲列表。

### 添加文件夹

停留在顶层时，点击右上角的添加文件夹按钮，在系统目录选择器中选中存放音乐的文件夹并授权。添加后，Lyrico 会自动开始扫描该文件夹。

如果已开启 `设置` → `音乐库管理` → `不扫描 60 秒以下音频`，短于 60 秒的音频会被跳过，适合过滤提示音、短片段和采样文件。

### 进入子文件夹

文件夹管理默认停在顶层。点击文件夹卡片进入下一级，顶部的面包屑会显示当前路径；点击面包屑上的任意一级可以直接回到对应层级，返回键或返回手势也会先回到上一级。面包屑下方显示当前层的文件夹和歌曲数量。

### 刷新文件夹

"刷新文件夹"会重新扫描对应文件夹。适合以下场景：
- 在系统文件管理器中新增了音频文件
- 删除了部分音频文件
- 用其他工具修改了文件的标签

### 隐藏与显示文件夹

**隐藏文件夹**：隐藏该文件夹及其子文件夹中的歌曲。隐藏后歌曲不出现在歌曲列表、艺术家列表、专辑列表和本地搜索结果中。

**显示文件夹**：恢复显示之前隐藏的文件夹及其歌曲。

隐藏不会删除文件，也不会移除文件夹记录。适合临时排除某些文件夹（如铃声、播客）的场景。

### 移除文件夹

从 Lyrico 中移除文件夹，并清除音乐库里的对应歌曲记录。本地音频文件不会被删除。之后仍可重新添加。

### 操作对比

| 操作 | 本地文件 | 文件夹记录 | 歌曲是否显示 |
|------|----------|------------|-------------|
| 隐藏文件夹 | 保留 | 保留 | 不显示，可再次显示 |
| 移除文件夹 | 保留 | 移除 | 不显示，需重新添加 |

## 艺术家海报

艺术家列表、艺术家详情和单曲编辑页优先显示属于这位艺术家的 **内嵌图片**。归属看图片的**描述**：描述里写的是哪位艺术家，这张图就归谁；没写描述的旧图片按"整首歌只有一位艺术家"来认定。某位艺术家没有可用的内嵌图片时，Lyrico 才会到海报文件夹里按 **文件名** 查找。

进入路径：`设置` → `音乐库管理` → `艺术家海报文件夹`

### 选择文件夹

首次进入时点击 **选择文件夹**，在系统目录选择器中选中存放海报的文件夹并授权，Lyrico 会立即读取其中的海报。

只读取所选文件夹中的文件，不会递归子文件夹。Lyrico 只使用一个海报文件夹；换文件夹是替换，不能同时挂多个。

### 文件夹操作

在艺术家海报页点右上角 ⋮，可以：

- **命名规则**：文件名与艺术家的对应规则。
- **文件夹详情**：文件夹路径、海报总数，以及其中 **匹配到库内艺术家** 的数量。匹配数为 0 时，检查文件名是否与艺术家名一致。
- **刷新文件夹**：重新读取文件夹里的文件。在系统文件管理器中增删或改名海报后用它；文件夹里没有可用海报时，也可以点它重试。
- **更换文件夹**：选择另一个文件夹。原文件夹里的文件不受影响；文件夹权限被回收或文件夹被删除时，按提示重新授权或更换文件夹。
- **移除文件夹**：停止使用所选文件夹中的海报，本地文件不会被删除。确认框里也会说明这一点。

### 海报命名规则

| 文件名 | 匹配的艺术家 |
|--------|-------------|
| `艺术家.jpg` | 名称完全一致的艺术家 |
| `艺术家_live.jpg` | 名称完全一致，且文件名以 `_` 接后缀 |
| `AC_DC.jpg`、`AC-DC.jpg`、`AC／DC.jpg` 或 `ACDC.jpg` | 名称中含文件名不能出现的字符（`\ / : * ? " < > \|`）的艺术家，如 `AC/DC` |

支持 JPG、JPEG、PNG、WebP 和 MP4（取视频首帧）。同一文件夹内，与艺术家名完全一致的文件名优先于带后缀的变体。每张海报会显示文件名匹配到的艺术家；匹配不上时显示 **未关联艺术家**。

### 单个海报文件的操作

点击海报卡片打开操作菜单：

- **查看海报大图**：全屏预览，手势见 [浏览音乐库](./browsing.md#大图预览)。
- **艺术家详情**：进入该艺术家的详情页。文件名匹配不到唯一的艺术家时不可用，并提示 **无法确定艺术家**。
- **重命名**：只改文件名，扩展名固定不能改。文件名决定归属，改名会改变匹配结果；名称无效或与文件夹内已有文件重复时无法确认。
- **裁剪**：只对 JPG、JPEG、PNG、WebP 图片出现，裁剪后直接替换原海报文件。MP4 没有裁剪项。
- **删除**：删除选中的海报文件，不可撤销。

### 三种操作的区别

| 操作 | 入口 | 效果 |
|------|------|------|
| 移除文件夹 | 艺术家海报页 ⋮ → **移除文件夹** | 只停止使用所选文件夹，海报文件保留 |
| 移除艺术家海报 | 艺术家列表的更多菜单、多选后的按钮，或艺术家详情页的 **移除艺术家海报** | 删除所选艺术家歌曲里的内嵌艺术家海报，并删除海报文件夹中属于他们的文件；封面等其他图片不受影响 |
| 导出内嵌海报到文件夹 | 艺术家详情页的 **导出内嵌海报到文件夹** | 把内嵌海报按艺术家名保存为图片文件；同名海报会被替换，没有内嵌海报的艺术家跳过 |

还没有海报文件夹时，导出会先让你选择文件夹，选中的文件夹会成为海报文件夹。移除和导出完成后都会提示成功、未修改和失败的数量。

在艺术家详情页从本地选择海报时，可以选 **从本地添加海报到文件夹**；图片会按艺术家名保存到这里，不修改歌曲文件。

## 扫描设置

在 **设置 → 音乐库管理 → 文件扫描** 中配置音频文件夹、短音频过滤和歌词索引，详见 [音乐库管理](./settings/library.md#文件扫描)

回放增益参数在 [标签编辑 → 回放增益](./settings/editing.md#回放增益) 中配置

## 文件夹权限问题

如果出现以下情况，Lyrico 会自动清理对应的音乐库记录并刷新索引：
- 文件夹权限丢失（如系统回收了存储权限）
- 文件夹被删除或移动
- 数据库中的歌曲在设备上已不存在

如果遇到"部分文件无法访问"的提示，可以尝试：
1. 进入 `文件夹管理`，移除受影响的文件夹。
2. 重新添加该文件夹并授权。
