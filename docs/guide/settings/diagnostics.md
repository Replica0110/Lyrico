# 问题排查

进入路径：**设置 → 问题排查**，页内先是日志记录，再是音乐库维护

## 日志记录

### 应用日志

进入路径：`设置` → `问题排查` → `应用日志`。

应用日志用于排查问题，覆盖以下类型：

- 崩溃与异常
- 元数据读写
- 批量操作
- 数据库
- 网络请求
- 插件执行

#### 使用日志

- 按 **"级别"** 筛选：DEBUG、INFO、WARN、ERROR。
- 按 **"类型"** 筛选：插件、网络、崩溃、批量等。
- 点击日志条目查看详细信息。
- **复制**单条日志或 **导出**日志文件。

#### 日志保留周期

可选：
- 不记录
- 7 天（默认）
- 30 天
- 90 天
- 永久保留

默认的 7 天适合日常排错。长期保留会占用更多存储空间。

### 问题诊断

进入 **设置 → 问题排查 → 问题诊断**

1. 先开始记录
2. 返回出现问题的功能，执行触发问题的操作
3. 回到问题诊断页停止记录
4. 预览报告，再按需分享或导出

这里记录临时诊断过程，不会自动修复问题，分享前应检查报告内容

## 音乐库维护

执行前需要确认，等待当前操作结束后再执行其他音乐库维护操作

### 重建音乐库索引

根据现有歌曲记录重新建立艺术家和专辑关联，适合归类或关联异常的情况

不会重新扫描音频文件，也不会改写标签，若需要发现新增文件或读取外部修改的标签，应刷新对应的音频文件夹

### 重置音乐库

清除歌曲记录、扫描目录和音乐库索引，设备上的音频文件会保留

执行后需要重新添加音频文件夹，配置导出不包含这些音乐库记录，不能用它恢复清空前的数据库
