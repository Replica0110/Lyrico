# 使用插件

当前版本支持 API 1–5 插件。新版 API5 插件需要支持该协议的 Lyrico；如安装时提示协议版本不支持，请先升级应用。旧版 API1–4 插件仍可使用。

本文面向插件使用者，说明 Lyrico 中插件的基本使用方式。这里不要求了解 JavaScript、manifest 或宿主 API。

插件负责提供在线搜索能力。启用插件后，Lyrico 可以通过插件搜索歌曲信息、歌词和封面；插件是否支持某项能力，取决于插件自身声明和实现。

## 插件包

Lyrico 插件通常以 ZIP 压缩包分发。一个插件包中至少包含：

```text
plugin.zip
└── com.example.source/
    ├── manifest.json
    └── source.js
```

有些压缩包可能同时包含多个插件。导入时，应用会扫描包内的 `manifest.json` 并列出可安装的插件。

## 导入插件

1. 在 Lyrico 中进入插件管理页面。
2. 选择插件 ZIP 压缩包。
3. 查看应用识别到的插件列表和导入结果。
4. 确认安装需要导入的插件。

如果插件包不符合格式要求，应用会拒绝导入，并显示对应错误原因。

## 启用与停用

插件管理页只有元数据源、歌词源和封面源三个 Tab。元数据源的开关和排序同时控制单曲主搜索与批量元数据匹配；歌词和封面开关分别用于对应的单曲与批量入口。插件声明的来源类型显示在名称下方。

关闭某一类型不会删除插件文件和配置，也不会影响其他类型。需要彻底移除时，可以卸载插件。

## 配置插件

插件可以声明自己的配置项，例如：

- API 地址
- Token 或 API Key
- 地区
- 封面尺寸
- 搜索偏好

配置项由插件在 `manifest.json` 中声明，Lyrico 会根据声明生成对应的配置界面。不同插件的配置项可能不同。

保存配置后，配置会在下一次搜索、歌词获取或封面搜索时传递给插件。

如果某个插件没有配置入口，通常表示它没有声明可配置项。

## 元数据应用

插件搜索结果会返回标准元数据字段，例如发行日期、专辑名、封面、作曲、作词等。单曲匹配和批量匹配由 Lyrico 负责决定哪些字段可以应用、以及是补充还是覆盖。

平台 ID、hash、歌词 ID 等私有信息只用于同一插件后续请求，不会显示为可写入的标签字段。

## 更新与卸载

导入相同插件 ID 的新版本时，Lyrico 会根据版本号判断是更新、覆盖还是降级。通常建议安装版本号更高的新版本。

卸载插件会移除插件文件，并清理对应插件配置。卸载前请确认不再需要该插件。

## 常见问题

### 插件启用后没有搜索结果

可能原因：

- 插件本身没有实现对应能力
- 插件需要配置 Token、API Key 或其他必填项
- 网络请求失败
- 对方服务返回格式变化，插件需要更新

### 插件配置保存后没有立即生效

配置会在插件执行搜索、获取歌词或搜索封面时传递给插件。已经完成的搜索结果不会自动重新刷新，需要重新执行搜索。

### 插件导入失败

常见原因包括：

- 压缩包内没有有效的 `manifest.json`
- 插件 ID 格式不合法
- 插件 API 版本不匹配
- 入口脚本不存在或路径不合法
- 压缩包或插件目录超过大小限制

## 在线订阅与更新

从插件管理页右上角的导入菜单打开“在线订阅”。顶部可添加订阅和刷新；点击订阅进入该源的插件列表，点击“返回”回到订阅列表。添加、编辑时填写目录链接和可选名称，支持 HTTP/HTTPS；同一目录链接不能重复添加。订阅的操作菜单提供刷新、编辑、启用/停用和删除。订阅列表中的“刷新”检查所有已启用订阅和已安装插件的更新地址；进入某个订阅后的“刷新”只刷新该源。

插件列表显示该源提供的版本；已安装版本不同时显示版本变化。点击条目右侧的安装、更新或降级按钮直接执行操作，不展示更新日志；降级会在按钮上明确标记。相同版本显示“已安装”，不兼容版本不能安装。下载百分比、校验和安装状态显示在操作按钮上；下载和安装过程可请求取消，失败或取消后可重试。取消下载不会卸载已有插件。同一个插件同时只执行一个安装任务。

进入插件管理页或订阅 Sheet 时会读取缓存，并在后台刷新尚未获取或缓存已满五分钟的目录；上次刷新失败的目录也会重新尝试。手动刷新会跳过缓存有效期。同一地址的并发请求合并处理，刷新失败保留上次成功列表并提示错误。

检查更新会合并已启用的订阅目录与已安装插件自身的 `updateUrl`，相同地址只请求一次。插件管理页展示兼容的最高更新版本；点击“更新”可确认版本、下载大小和来源，不展示更新日志。最高更新版本存在多个不同 SHA-256 的包时，需要在确认弹层中选择来源。订阅列表中的插件始终与该源提供的版本比较。实际安装来源和包哈希会保存，包内的 `updateUrl` 不会被订阅地址覆盖；安装来源可在插件配置页查看。

停用订阅后不再通过该订阅自动检查更新；如果同一地址仍是某个已安装插件自身的更新地址，仍会检查该地址。删除订阅不会卸载插件、清空插件配置或改写插件自身的更新地址。关闭 Sheet 后任务在当前应用进程中继续；重新进入对应订阅可查看状态或取消任务，已安装插件的更新进度也会显示在插件管理页。应用进程终止后下载不会自动续传，需要重新发起安装或更新。
