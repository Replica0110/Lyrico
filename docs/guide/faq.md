# 常见问题

## 基本使用

### 首次启动为什么会同时申请通知和音频权限？

Android 13 及以上版本会在启动时将两个尚未授予的权限作为同一批请求：

- 音频权限用于扫描、读取和管理本地音乐。
- 通知权限用于显示批量任务等后台处理进度。

音频权限是建立和管理音乐库所需的权限；通知权限被拒绝后仍可浏览和编辑，但可能看不到后台任务通知。Android 12 及以下只会请求音频读取权限。若误拒权限，可进入系统 `设置` → `应用` → `Lyrico` → `权限` 重新开启。

### 为什么点击歌曲不放音乐？

Lyrico 是一个标签编辑工具，不是音乐播放器。点击歌曲的默认行为是进入"编辑元数据"页面。要播放音乐，请使用歌曲右侧更多菜单中的"播放音乐"。

### 保存后歌曲信息没有变化？

保存操作将修改写入音频文件本身，而不是 Lyrico 的数据库。请确认：
1. 保存时是否提示"保存成功"。
2. 文件所在目录是否有写入权限。部分 Android 版本可能需要额外授权。
3. 用其他音乐播放器查看是否显示了新标签。

### 通过其他应用或系统分享打开文件，编辑后无法保存？

从外部应用通过"分享"或"打开方式"进入 Lyrico 编辑音频时，如果出现无法保存的情况，通常是因为 Lyrico 缺少音频访问权限。

解决方法：在系统设置中授予 Lyrico 音频访问权限（设置 → 应用 → Lyrico → 权限 → 音乐和音频），授权后即可正常保存。

### 如何删除音乐库中的歌曲但不删除文件？

你可以使用"隐藏文件夹"功能（`设置` → `音乐库管理` → `音频文件夹`）将歌曲从库中隐藏，文件不会被删除。

如果只是个别歌曲不想显示，可以将它们移到单独的文件夹中，然后隐藏该文件夹。

### 音频文件里的内嵌海报和海报文件夹里的海报，哪个优先？

按 **艺术家** 逐个判定：优先用音频文件里属于这位艺术家的 **内嵌海报**（描述写着这位艺术家的图片，或没写描述的旧图）。这位艺术家没有可用的内嵌海报时，才会到 **海报文件夹** 里按文件名查找。所以某位艺术家已经有内嵌海报时，海报文件夹里的同名文件对这位艺术家不生效，但不影响同一首歌里的其他艺术家。

描述对不上任何艺术家的内嵌海报（常见于改过艺术家字段之后）会单独占一页，标签显示为 **“未标注”** 或它原本的描述，可在菜单里重新指定归属。

详见 [艺术家海报](./library.md#艺术家海报)。

### 移除艺术家海报和移除海报文件夹有什么区别？

**移除艺术家海报**：删除这位艺术家的内嵌海报，并删除海报文件夹里以这位艺术家命名的海报文件。入口在艺术家列表的更多菜单、多选后的按钮，以及艺术家详情页。操作不能撤销。

**移除文件夹**：在 `设置` → `音乐库管理` → **艺术家海报文件夹** 中操作，只是停止使用所选文件夹中的海报，不会删除任何文件。需要时重新添加即可。

### 添加了海报文件夹，艺术家仍然没有海报？

按顺序检查：

1. 海报文件是否位于所选文件夹的 **直接子级**（Lyrico 不会查找子文件夹）。
2. 文件名是否与艺术家名一致（如 `周杰伦.jpg`）。名称中含 `\ / : * ? " < > |` 的艺术家需要用下划线等替代，例如 `AC/DC` 存为 `AC_DC.jpg`。
3. 该艺术家是否已有内嵌海报——内嵌海报优先，会盖过海报文件。
4. 文件夹详情中“匹配到库内艺术家”的数量是否为 0。为 0 说明文件名和艺术家名不一致。

见 [艺术家海报](./library.md#艺术家海报)。

### 艺术家列表里一位艺术家被拆成了多个？

这是"艺术家拆分"按分隔符把多位艺术家拆开的结果，音频文件中的标签本身不会被修改。如果不希望某位艺术家被拆分，可以在 `设置` → `音乐库管理` → `艺术家拆分规则` 的"不拆分明细"中添加该艺术家名，然后重建艺术家索引。

## 界面

### 如何切换应用语言？

进入 `设置` → `外观` → `应用语言`，选择"跟随系统"、"English"、"简体中文"、"繁體中文（台灣）"或"繁體中文（香港）"。切换后界面立即生效，不需要重启应用。

### 底部导航栏变成了悬浮样式，怎么改回去？

在 `设置` → `外观` 中关闭 **"悬浮导航栏"** 即可恢复普通底栏。开启时还可以在该项下方选择"悬浮导航栏效果"（无 / 毛玻璃 / 液态玻璃）。见 [外观](./settings/appearance.md#悬浮导航栏)。

### 切换界面风格后，模糊和悬浮导航栏不见了？

**模糊** 和 **悬浮导航栏** 只在 **Miuix** 界面风格下提供。在 `设置` → `外观` → **界面风格** 中切到 **SaltUI** 后，这两项会隐藏；之前的开关状态会保留。切回 **Miuix** 即可重新设置。见 [界面风格](./settings/appearance.md#界面风格)。

### 歌曲列表左边的数字是什么？

左侧数字是 **音轨编号**，来自歌曲的"音轨号"标签。标签中包含碟号时会显示为 `音轨号 (碟号)`；没有音轨号时显示 `—`。只有专辑详情和艺术家详情的歌曲列表会显示它。

## 插件相关

### 插件安装了但搜索不到结果？

依次检查：
1. 插件是否已 **启用**（开关是否为开）。
2. 插件是否 **支持当前操作**（有些插件只支持歌曲搜索，不支持歌词或封面）。
3. 插件是否需要 **Token 或 API Key**，如果需要在插件配置中填写。
4. 网络是否正常。
5. 查看 `设置` → `问题排查` → `应用日志`，筛选"插件"类型查看错误信息。

### 插件 ZIP 导入失败？

常见原因：
- ZIP 包内没有有效的 `manifest.json` 文件。
- 插件 API 版本与 Lyrico 不兼容。
- 插件包结构或入口脚本不符合要求。
- 插件包超过大小限制（单个插件 5 MB，压缩包解压后 30 MB）。

具体原因会在"发现插件包"弹窗的"无法安装"区域显示。

### 如何获取更多插件？

官方插件仓库：[Lyrico-Plugins](https://github.com/Replica0110/Lyrico-Plugins)，覆盖 QQ 音乐、网易云音乐、酷狗音乐、Apple Music 等平台。

## 批量操作

### 如何一次选中多首歌？

进入多选模式有几种方式：
- **长按**任意歌曲。
- 在歌曲上**向左或向右滑动**。
- 滑动第一首歌曲设置区间起点，再滑动另一首完成区间选择。

详见 [批量操作](./batch.md#进入选择模式)。

### 批量任务切到后台后卡住，回到应用又继续？

系统的电池优化或后台运行策略可能暂停应用。遇到这种情况，可先检查 Lyrico 的后台运行设置，ColorOS 等系统还可能有单独的后台活动限制。

1. 长按 Lyrico 图标，进入系统 **应用信息**，找到 **电池用量**、**耗电管理** 或类似设置。
2. 将 Lyrico 的后台运行策略设为 **无限制 / 不限制**，或开启 **允许后台活动 / 允许后台运行**。
3. 如果系统另有 **电池优化** 设置，为 Lyrico 选择 **不优化 / 忽略电池优化**，并检查省电模式是否仍在限制 Lyrico。

不同品牌和系统版本的选项名称、位置可能不同，后台运行权限与电池优化也可能需要分别设置。允许持续后台运行可能增加耗电。

调整后仍出现停顿，可在 `设置` → `问题排查` → `应用日志` 中筛选 **批量**，查看任务记录并附上日志反馈；也可暂时保持应用在前台完成任务。

参考：[Android 后台优化说明](https://developer.android.com/topic/performance/background-optimization)、[World Run 的 OPPO 后台运行设置说明](https://donate.wingsforlifeworldrun.com/en/wflwr-app-settings/android/oppo)。

### 批量匹配处理到一半失败了？

可能原因：
- 并发数设置过高，被对方平台限流。降低并发数后重试。
- 某些歌曲的标题/艺术家为空，搜索关键词无效。
- 插件网络请求超时。

你可以在 `设置` → `任务历史` 中查看每首歌的具体失败原因。

### 批量重命名后文件名没有变化？

检查：
1. 占位符对应的标签是否为空（如 `@1` 对应标题，如果标题为空则生成空文本）。
2. 生成的文件名是否在预览中正确显示。
3. 是否有多首歌曲生成了相同文件名（Lyrico 会自动追加数字后缀避免冲突）。

### 计算回放增益失败怎么办？

计算失败时会显示原因；批量任务可到 `设置` → `任务历史` → **回放增益计算** 的 **失败** 页查看，单首失败不影响其他歌曲。

文件损坏、无法识别编码或解码数据为空时，先用播放器确认文件能否正常播放；仍失败可到应用日志筛选 **批量** 查看错误。

## 歌词

### 逐字歌词为什么不显示？

- 确保歌词模式设置为"逐字歌词"或"增强型逐字歌词"。
- 插件返回的歌词需要包含逐字时间信息。如果源数据只有普通 LRC，无法转换为逐字歌词。

### 如何把繁体歌词转为简体？

在编辑页的歌词选项中，使用"简繁转换"功能。也可以在 `设置` → `标签编辑` 中设置"中文文本转换"为"繁体转简体"，此后搜索的歌词会自动转换。

## 其他

### 应用占用空间太大？

主要是封面图片缓存。前往 `设置` → `数据管理` → `清理缓存` 清理图片缓存。

正常情况下不会。但建议在更新前通过 `设置` → `数据管理` → `导出设置` 备份配置，以防万一。
