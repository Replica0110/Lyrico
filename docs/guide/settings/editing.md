# 标签编辑

进入路径：**设置 → 标签编辑**

## 标签写入

### 编辑字段

进入 **设置 → 标签编辑 → 编辑字段**，统一管理内置字段和自定义标签。

- 长按字段拖动，调整编辑页中的顺序；右侧开关控制显隐。
- 回放增益的菜单中可选择 **管理字段**，调整组内字段的顺序和显隐。组开关与成员开关分别保存。
- 在字段的菜单里选择 **查看歌曲**，查看该字段已填写或未填写的歌曲。
- 点击顶栏恢复默认按钮，可重置字段配置；不会修改歌曲数据。

配置用于单曲编辑、批量编辑和批量匹配。关闭字段不会清空文件中已有的标签。

#### 查看字段歌曲

**查看歌曲** 会打开该字段自己的歌曲页面。顶部两个标签页是 **已填写** 和 **未填写**。

- 点击歌曲进入单曲编辑；改完字段或重命名文件后返回，列表随音乐库更新。
- 长按或滑动进入多选模式，选中后可执行和歌曲列表一样的批量操作，例如编辑标签、匹配元数据、重命名和删除。
- 封面要读取音频文件才能判断。读取失败的歌曲不会归入 **未填写**，列表顶部会提示“部分歌曲读取失败”，点 **重试** 重新读取。

#### 自定义标签

点击右上角 **“+”**，点击候选标签可将键名填入输入框，也可手动输入标签键（如 `SOURCE`），确认后添加。键名会去除首尾空白并转为大写；不能重复、包含换行或超过 64 个字符。

自定义标签可通过菜单删除。删除只移除配置，不会删除歌曲中的标签数据。

### 多艺术家分隔符

选择连接多个艺术家名称时使用的分隔符，可选顿号、斜杠、逗号或分号

它与音乐库中的 [艺术家拆分规则](./library.md#艺术家拆分规则) 分开配置

## 歌词内容

### 歌词格式

选择搜索歌词时优先获取的歌词格式：

- **逐行歌词**：传统的逐行 LRC 格式。
- **逐字歌词**：包含逐字时间轴的歌词。
- **增强型逐字歌词**：包含逐字时间轴和更多元数据的歌词。
- **TTML**：TTML 格式歌词（Timed Text Markup Language）。

#### TTML 信息保留

输出 TTML 时，会保留源数据中受支持的演唱者、段落时间、语言、head 元数据、逐词音译和多音节 Ruby 注音。Ruby 时间会随歌词偏移同步调整；缺失边界会参考相邻音节和词时间补齐。正文时长不随偏移改变。

LRC 无法保留演唱者、段落和 Ruby 等 TTML 专属结构；逐字 LRC 可保留音译时间戳。解析和重写不保证保留任意 XML 结构，API5 插件可通过扩展字段提供受支持的信息。

### 音译

获取歌词时包含音译内容

### 翻译

获取歌词时包含翻译内容

### 仅保留翻译歌词

需先开启“翻译”，有译文的行使用译文，缺少译文的行保留原文

### 歌词内容顺序

同一时间点有多行歌词时，行式歌词按设定的顺序输出。入口：**设置 → 标签编辑 → 歌词内容顺序**；搜索歌词和搜索结果的歌词设置面板里也有同一份列表，两处改的是同一个设置。

长按列表中的 **原词**、**音译** 或 **翻译** 并拖动即可排序，默认顺序是原词 → 音译 → 翻译。只影响 LRC 类行式歌词（逐行、逐字、增强型逐字）中这三类内容的先后，TTML 歌词保持自己的结构。

列表只显示已启用的内容：关闭 **音译** 后它不再出现，重新开启时原来的位置还在。开启 **仅保留翻译歌词** 时，列表只剩 **翻译**。

歌词内容顺序是全局设置，不改动已有歌词。要调整已有歌词里同一时间点的多行顺序或删掉其中一行，用 **歌词选项 → 歌词整理 → 按句排序**：它直接改写歌词文本，支持 LRC，TTML 和只有一行的时间点不处理。详见 [歌词整理](../single-song.md#歌词整理)。

修改后需重新搜索才能应用到已有搜索结果，不会改写已经保存到音频文件中的歌词

## 文本处理

### 中文文本转换

"中文文本转换"会应用于搜索到的文本元数据和歌词。ID、日期、数字、URL 和封面不会受转换影响。

可选模式：
- 不转换
- 简体转繁体
- 繁体转简体

### 非歌词内容过滤规则

在“歌词整理”中选择“移除非歌词内容”时，使用非歌词内容过滤规则清理作词、作曲、来源等非歌词行。

过滤规则在 `设置` → `标签编辑` → `非歌词内容过滤规则` 中维护。规则按关键词匹配，不区分大小写。歌词行包含任一关键词就会被移除；逐字歌词按整行文本判断。

常见过滤示例：`作词：`、`作曲：`、`编曲：`、`来源` 等。

### 移除空行

开启后，在歌词输出和清理时移除空行

## 回放增益

### 目标响度

计算 ReplayGain 时使用的目标响度，默认 **-18 LUFS**

预设为 **-23 LUFS（EBU R128）**、**-18 LUFS（默认）** 和 **-14 LUFS（流媒体常用）**，也可输入 **-60 到 0 LUFS** 的自定义值

### 回放增益峰值类型

- **采样峰值**：默认测量方式，符合传统 ReplayGain 峰值语义
- **真实峰值**：通过过采样插值估计重建后的峰值

两者以 1.0 表示数字满刻度，压缩音频解码后的采样峰值也可能超过 1.0

修改这两项只影响之后的计算，要更新歌曲标签，需要重新执行 [计算回放增益](../single-song.md#replaygain)
