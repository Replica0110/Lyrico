# 歌词设置

进入 **设置 → 标签编辑 → 歌词内容**，配置歌词搜索、格式和输出

<a id="歌词模式"></a>

## 歌词格式

选择搜索歌词时优先获取的歌词格式：

- **逐行歌词**：传统的逐行 LRC 格式。
- **逐字歌词**：包含逐字时间轴的歌词。
- **增强型逐字歌词**：包含逐字时间轴和更多元数据的歌词。
- **TTML**：TTML 格式歌词（Timed Text Markup Language）。

## 翻译与音译

- **音译**：开启后，搜索歌词时请求音译内容（适合日语等需要读音转写的歌曲）。
- **翻译**：开启后，搜索歌词时请求翻译内容。
- **仅保留翻译歌词**：需先开启“翻译”。有译文的歌词行使用译文，缺少译文的行保留原文。

## 歌词内容顺序

同一时间点有多行歌词时，行式歌词按设定的顺序输出。入口：**设置 → 标签编辑 → 歌词内容顺序**；搜索歌词和搜索结果的歌词设置面板里也有同一份列表，两处改的是同一个设置。

长按列表中的 **原词**、**音译** 或 **翻译** 并拖动即可排序，默认顺序是原词 → 音译 → 翻译。只影响 LRC 类行式歌词（逐行、逐字、增强型逐字）中这三类内容的先后，TTML 歌词保持自己的结构。

列表只显示已启用的内容：关闭 **音译** 后它不再出现，重新开启时原来的位置还在。开启 **仅保留翻译歌词** 时，列表只剩 **翻译**。

歌词内容顺序是全局设置，不改动已有歌词。要调整已有歌词里同一时间点的多行顺序或删掉其中一行，用 **歌词选项 → 歌词整理 → 按句排序**：它直接改写歌词文本，支持 LRC，TTML 和只有一行的时间点不处理。详见 [歌词整理](../single-song.md#歌词整理)。

## TTML 信息保留

输出 TTML 时，会保留源数据中受支持的演唱者、段落时间、语言、head 元数据、逐词音译和多音节 Ruby 注音。Ruby 时间会随歌词偏移同步调整；缺失边界会参考相邻音节和词时间补齐。正文时长不随偏移改变。

LRC 无法保留演唱者、段落和 Ruby 等 TTML 专属结构；逐字 LRC 可保留音译时间戳。解析和重写不保证保留任意 XML 结构，API5 插件可通过扩展字段提供受支持的信息。

## 注意事项

修改歌词格式、音译或翻译设置后，已有的搜索结果 **不会自动刷新**。需要重新搜索歌词才会使用新配置。

已经保存到音频文件中的歌词不受影响。
