# 浏览音乐库

Lyrico 提供三种浏览维度——歌曲、艺术家、专辑——以及本地搜索，帮助你快速找到想要的音乐。

## 三个主视图

底部导航栏包含三个标签页：

### 歌曲

所有已扫描歌曲的列表。默认按标题排序，支持字母侧边栏快速跳转。

- 点击歌曲进入 [编辑元数据](./single-song.md)。
- 长按歌曲或左右滑动进入多选模式（用于 [批量操作](./batch.md#进入选择模式)）。

### 艺术家

按艺术家分组的列表。如果开启了艺术家拆分（`设置` → `音乐库管理` → `艺术家拆分规则`），多个艺术家的歌曲会分别归类。

点击艺术家进入艺术家详情页，详情页包含 **"单曲"** 和 **"专辑"** 两个标签页，可以查看该艺术家的所有歌曲和参与的专辑。

长按艺术家或左右滑动进入多选模式，选中后点右下角按钮可以批量 **移除艺术家海报**。详情页顶部的圆形艺术家封面是海报入口，点击打开 **艺术家海报选项**，见 [艺术家海报](#艺术家海报)。

### 专辑

按专辑封面网格展示。点击专辑进入专辑详情页，可以查看该专辑下的所有歌曲。

专辑详情页中的歌曲列表同样支持点击编辑、长按多选等操作。

**音轨编号**：在专辑详情和艺术家详情的歌曲列表中，每首歌的左侧会显示音轨编号；标签中包含碟号时，会一并显示为 `音轨号 (碟号)` 的形式。标签中缺少音轨号时显示 `—`。

::: tip 悬浮导航栏
如果觉得底栏占据内容空间，可以在 `设置` → `外观` 中开启 **"悬浮导航栏"**，并选择毛玻璃或液态玻璃效果。悬浮导航栏、悬浮效果和模糊只在 **Miuix** 界面风格下可用；切换到 **SaltUI** 后底栏使用固定样式，外观设置里也不再出现这几项。见 [外观](./settings/appearance.md#悬浮导航栏)。
:::

## 艺术家海报

艺术家列表每行的更多菜单（⋮）提供 **查看海报大图**、**裁剪艺术家海报** 和 **移除艺术家海报**。视频海报的裁剪项会注明 **视频海报不支持裁剪**。这位艺术家没有任何可用海报时，菜单会显示 **暂无艺术家海报**，并提供 **选择艺术家海报** 入口。

在艺术家详情页点击顶部的圆形封面，打开 **艺术家海报选项**：

- **查看海报大图**：全屏预览当前海报。
- **从本地选择艺术家海报**：选好图片后，再决定 **写入歌曲内嵌海报** 还是 **从本地添加海报到文件夹**。后者不修改歌曲文件。
- **移除艺术家海报**：删除这位艺术家在各首歌曲里的内嵌海报，并删除海报文件夹中属于这位艺术家的文件。需要确认。
- **导出内嵌海报到文件夹**：把内嵌海报按艺术家名保存为图片文件。同名海报会被替换；这位艺术家没有内嵌海报时不会写入文件。

还没有海报文件夹时，导出会先让你选择文件夹，选中的文件夹会成为海报文件夹。完成后提示成功、未修改和失败的数量。

在艺术家列表中多选艺术家后，右下角按钮只有 **移除艺术家海报**，效果与单张移除相同；导出需要进艺术家详情页。

### 大图预览

海报大图共用同一套预览界面，操作只对当前显示的海报生效：

- 双指缩放，放大后拖动平移。
- 左右滑动切换海报；有多张时，底部缩略图也可以直接选择。
- 单击画面显示或隐藏顶栏和底栏。
- 在画面上向上拖动打开 **图片信息**，向下拖动关闭；也可以点底部的 **图片信息**。
- 底部按钮：**分享**、**裁剪**、**图片信息**。

图片信息显示尺寸、文件大小、格式，以及来源是 **内嵌** 还是 **外部文件**，并给出文件名或路径。

MP4 海报会直接播放视频，带播放控制。视频不能裁剪，预览里不显示裁剪按钮。

裁剪只改当前这张海报：内嵌海报会改写对应的歌曲文件；文件夹海报会替换该文件本身。

## 排序

歌曲、艺术家和专辑列表都支持排序。点击列表顶部的排序按钮可以切换排序方式：

**歌曲排序选项：**
- 标题
- 艺术家
- 专辑
- 修改日期
- 添加日期
- 文件大小
- 时长
- 扩展名

**艺术家排序选项：**
- 名称
- 歌曲数量
- 专辑数量

**专辑排序选项：**
- 名称
- 艺术家
- 歌曲数量
- 年份

专辑网格的列数也可以在专辑页中调整。

## 本地搜索

点击导航栏中的搜索图标进入 **"本地搜索"**。

本地搜索会同时匹配 **标题、艺术家、专辑和文件名**。输入关键词后，结果按"艺术家"、"专辑"、"单曲"三个区域分段显示。

::: warning 注意
已被隐藏文件夹中的歌曲不会出现在普通列表和本地搜索结果中。如需恢复显示，前往 `设置` → `音乐库管理` → `音频文件夹` 中操作。
:::

## 播放歌曲

Lyrico 是一个标签编辑工具，不是音乐播放器。点击歌曲默认进入编辑页而非播放。

要播放歌曲：
- 在歌曲列表中，点击歌曲右侧的 **更多菜单**（⋮），选择 **"播放音乐"**。
- 在编辑页中，点击播放按钮。

两种入口都会打开 **“播放方式”** 面板，选择已安装的播放器或系统选择器。

## 歌曲菜单

歌曲列表右侧的更多菜单（⋮）提供以下操作：

| 操作 | 说明 |
|------|------|
| 播放音乐 | 调用外部播放器播放音频 |
| 歌曲信息 | 查看标题、艺术家、专辑、时长、比特率、采样率、声道、文件路径、文件大小等详情，可复制内容 |
| 分享歌曲 | 通过系统分享面板发送音频文件 |
| 重命名文件 | 修改文件名，保留原扩展名。**不会修改歌曲标题标签** |
| 删除歌曲 | 删除本地音频文件。**删除操作不可撤销** |

在已进入多选模式时，更多菜单会被复选框替代，此时点击歌曲用于切换选中状态。
