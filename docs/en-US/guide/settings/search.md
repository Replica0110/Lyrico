# Online search

Open **Settings → Online search**.

## Sources

<a id="plugin-management"></a>

### Plugin Manager

Import, enable, disable, reorder, configure or uninstall source plugins. See [Using Plugins](../plugins.md).

### Search source tab style

Choose icon only, text only, or icon and text for source tabs on the results page.

## Result display

### Results per load

Set how many candidates each source loads at a time. Use Load more at the bottom of the results list to fetch more candidates.

Larger values increase network traffic and image-cache use.

<a id="show-all-fields"></a>

### Show empty fields

When enabled, fields without values appear as "(empty)" in result details. Otherwise, only populated fields are shown.
