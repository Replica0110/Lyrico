# 批量操作

批量操作用于一次处理多首歌曲。

## 进入选择模式

执行任何批量操作前，先进入 **多选模式** 并选中歌曲。有以下方式：

### 方式一：长按进入

**操作流程：**

1. 在歌曲列表中，**长按**任意歌曲条目。
2. 进入选择模式后，该歌曲自动被选中，顶部栏显示"已选择 1 项"。
3. 此时点击其他歌曲可继续追加或取消选择。

### 方式二：滑动进入

**操作流程：**

1. 在任意歌曲条目上 **向左或向右滑动**。
2. 滑动距离达到阈值后，进入选择模式并选中该歌曲。

### 区间选择（快速选中连续歌曲）

滑动选择可以一次性选中一段连续的歌曲，适合批量处理相邻条目。

**操作流程：**

1. 在未进入选择模式时，向左或向右滑动第一首歌曲。该歌曲被选中，并作为 **区间起点**。
2. 在同一列表中继续滑动另一首 **尚未选中的歌曲**。
3. Lyrico 会自动选中区间起点和目标歌曲之间的所有列表项。
4. 区间完成后，可以继续点击或滑动其他歌曲追加选择。

界面会在滑动时显示"进入多选"、"区间起点"或"区间终点"提示。区间选择基于当前列表的可见顺序；如果列表经过搜索或排序，区间范围也会随之变化。

### 选择模式下的操作

进入选择模式后：

- 歌曲条目右侧从"更多按钮"变为 **复选框**。点击歌曲或点击复选框都会切换选中状态。
- 顶部栏提供三个操作：
  - **全选**：选中当前列表中的全部歌曲。
  - **取消全选**：清空当前选择。
  - **关闭**：退出选择模式并清空选择。
- 按系统返回键也可退出选择模式。

### 打开批量操作菜单

选择至少一首歌曲后，页面右下角会显示 **展开按钮（FAB）**。展开后可执行的批量操作包括：

- 计算回放增益
- 转换歌词格式
- 歌词整理
- 导出歌词
- 导出封面
- 重命名
- 编辑标签
- 标签匹配
- 批量匹配歌词
- 批量匹配封面
- 删除
- 分享

## 标签匹配

**"标签匹配"** 使用已启用的元数据源写入标题、艺术家、专辑等元数据字段。歌词与封面分别通过独立的 **"批量匹配歌词"**、**"批量匹配封面"** 任务处理。

在批量菜单中选择对应任务，确认并发数和写入配置后开始。三类任务分别使用插件管理中对应类型的启用状态与优先级；仅提供歌词的源可直接返回候选，封面候选会按本地歌曲信息评分选择。

**完整操作流程：**

1. 在歌曲列表中，通过长按或滑动方式 **进入选择模式**。
2. 选中需要匹配的歌曲（可以全选或手动勾选）。
3. 点击右下角展开按钮，选择 **"标签匹配"**。
4. 在"批量匹配配置"页面中，确认或调整 **并发数**。
5. 点击确认开始任务。
6. 任务执行期间会显示进度。可以在进度弹窗中查看实时状态，也可以返回后在 `设置` → `任务历史` 中查看。

**匹配前请确认：**

- `设置` → `在线搜索` → `插件管理` 中至少有一个插件已启用。
- 插件顺序符合你的需要（排在前面的插件优先参与搜索）。
- 需要 Token、API Key、地区等配置的插件已保存配置。
- 相关字段的写入规则已设置好（"补充"或"覆盖"，不应为"禁用"）。

**并发数说明：**
并发数越高处理速度越快，但更容易触发网络失败或平台限流。出现频繁请求失败时，应降低并发数后重新执行。

**按文件名匹配：**
如果在批量匹配配置弹层中启用了“按文件名匹配”，批量匹配会忽略音频文件已有的标题和艺术家标签，改用文件名作为搜索依据。该模式适合文件标签混乱但文件名规范的音乐库。

## 编辑标签

**“编辑标签”** 把相同的字段值批量写入多首歌曲。配置页只列出在 [编辑字段](./settings/editing.md#编辑字段) 中为“批量编辑”开启的字段。

**操作流程：**

1. 在歌曲列表中长按或滑动 **进入选择模式**，选中歌曲。
2. 点击右下角展开按钮，选择 **“编辑标签”**。
3. 在 **“配置”** 页填写要写入的字段。
4. 切换到 **“预览（N）”** 页检查修改。N 为有改动的歌曲数。
5. 点击右上角的 **确认（✓）** 按钮开始写入。底部弹层显示进度和成功、跳过、失败数量，可点 **“中止”** 停止。
6. 写入结束后点 **“确认”** 关闭弹层返回。有失败项时会留在编辑页，可在任务历史中查看。

**字段的三种状态：**

| 状态 | 界面                                       | 结果 |
|------|------------------------------------------|------|
| 保持原值 | 输入框显示 `<keep>`，字段标题为 **“标题（无修改）”**  | 不写入该字段，原值保留 |
| 清空字段 | 输入框为空                                    | 清空该标签 |
| 写入新值 | 输入框里是填写的文本                               | 写入所有选中歌曲 |

“（无修改）”只是不写入，**不等于清空**。要清空字段，把输入框内容删空；未修改的单行字段右侧有 **✕**，点它也能直接清空。字段修改后，右侧图标变成 **撤销**，点击回到“（无修改）”。

**从已选歌曲取值：** 每个字段右侧的列表图标打开 **“从已选歌曲中选择”**，列出所选歌曲在该字段已有的非空值（去重）。点一个值填入字段；所选歌曲都没有该字段的值时显示“已选歌曲中没有可用值”。

**其他操作：**

- **封面**：点封面区域，可以 **从本地选择封面**、**从已选歌曲中选择封面**、**从同专辑选择封面**、**移除封面** 或 **还原封面**。从同专辑选择时，选中歌曲的专辑和艺术家需要一致，或者在配置页先填好专辑。
- **自定义标签**：在配置页右下角展开按钮里选择 **“添加自定义标签”**；也可以在 [编辑字段](./settings/editing.md#编辑字段) 中添加并开启。
- **编辑字段**：配置页右下角展开按钮里的 **“编辑字段”** 打开字段的显隐和顺序设置。
- **使用说明**：配置页右下角展开按钮里的 **“使用说明”** 查看以上规则。

## 重命名文件

**"重命名"** 只修改音频文件名，保留原扩展名，不会修改歌曲标题、艺术家等标签。

**完整操作流程：**

1. 在歌曲列表中，通过长按或滑动方式 **进入选择模式**。
2. 选中需要重命名的歌曲。
3. 点击右下角展开按钮，选择 **"重命名"**。
4. 在"命名格式"中输入格式。格式使用占位符代表标签字段，例如 `@2 - @1` 会生成"艺术家 - 标题"形式的文件名。
5. 如果需要替换文件名中的特殊字符，进入 **"配置字符映射"** 调整替换规则。
6. 切换到 **"预览"** 页，查看旧文件名和新文件名的对照。
7. 确认无误后，点击 **"执行重命名"**。

**占位符说明：**

| 占位符 | 字段 |
|--------|------|
| `@1` | 标题 |
| `@2` | 艺术家 |
| `@3` | 专辑艺术家 |
| `@4` | 专辑 |
| `@5` | 音轨号 |
| `@6` | 碟号 |
| `@7` | 年份 |
| `@8` | 流派 |

如果某个占位符对应的标签为空，该部分会生成空文本。生成结果为空时，保留原文件名。多个文件生成相同名称时，Lyrico 会自动追加 ` (1)`、` (2)` 等后缀以避免冲突。

## 转换歌词格式

1. 进入多选模式，选中歌曲，在右下角菜单选择 **“转换歌词格式”**。
2. 选择目标格式和并发数。
3. 点击 **“处理”** 开始任务，结果直接写入文件。

无歌词的歌曲会跳过。源歌词没有逐字时间轴时，不能转换为需要逐字时间信息的格式。

## 歌词整理

1. 选中歌曲，在右下角菜单打开 **“歌词整理”**，选择一项操作：
   - **按句排序**：调整同一时间点多行歌词的顺序，或移除其中一行。
   - **移除空行**：删除空白或仅含占位符的歌词行。
   - **移除非歌词内容**：按 [过滤规则](./settings/editing.md#非歌词内容过滤规则) 清理作词、作曲等行。
2. 调整所选操作的配置及并发数。
3. 点击 **“处理”** 开始任务，结果直接写入文件。

任务记录可在 **设置 → 任务历史 → 歌词处理** 中查看。

排序设置与单曲编辑相同，见 [歌词整理](./single-song.md#歌词整理)。无歌词或处理后没有变化的歌曲会跳过。

## 计算回放增益

**“计算回放增益”** 会分析选中歌曲并写入曲目增益、曲目峰值和参考响度。只有这三项都已填写，且参考响度与当前设置一致时，歌曲才会跳过；有字段缺失或参考响度已变更时会重新计算并覆盖曲目 ReplayGain 值。

解码先使用系统解码器。系统解码失败时，Lyrico 会自动改用内置 FFmpeg 解码器重试，ALAC、APE 歌曲常无法由系统解码器处理，不需要额外设置。后备解码也可能失败，Lyrico 不保证能解码所有编码；仍失败的歌曲会记为失败，不影响其他歌曲，可在任务历史的“失败”标签页查看。

**完整操作流程：**

1. 在歌曲列表中，通过长按或滑动方式 **进入选择模式**。
2. 选中需要计算的歌曲。
3. 点击右下角展开按钮，选择 **"计算回放增益"**。
4. 确认或调整并发数。
5. 点击确认开始任务。

并发数越高扫描速度越快，但会增加 CPU 和内存占用。处理大量歌曲时如出现发热、卡顿或失败增加，应降低并发数。

计算使用的目标响度取自 `设置` → `标签编辑` → `目标响度`（默认 -18 LUFS）。

## 导出歌词和封面

**“导出歌词”** 和 **“导出封面”** 都可以将文件导出到统一的指定文件夹，或分别保存到每首音频所在目录。

**完整操作流程：**

1. 在歌曲列表中，通过长按或滑动方式 **进入选择模式**。
2. 选中需要导出的歌曲。
3. 点击右下角展开按钮，选择 **“导出歌词”** 或 **“导出封面”**。
4. 选择 **“指定文件夹”** 或 **“音频同目录”**；选择指定文件夹时，再在系统文件选择器中选择目标目录。
5. Lyrico 开始导出。无歌词/封面的歌曲会跳过。

导出规则：
- TTML 歌词导出为 `.ttml`；其他歌词导出为 `.lrc`。
- 选择“音频同目录”时，每首歌词或封面会分别写入对应音频文件所在的目录，所选音频可以来自不同目录。
- 封面以原音频文件名为基础导出为 `.jpg`。
- 目标目录中已有同名文件时，可能会复用该文件并写入新内容。

## 删除和分享

**"删除"**：弹出"删除所选文件？"确认框。确认后删除本地音频文件，不可撤销。

**"分享"**：调用 Android 系统分享面板，发送选中的音频文件。

这两项操作不创建后台任务，直接执行。

---

## 任务历史

除"删除"和"分享"外，所有批量操作都会创建后台任务。任务入口：`设置` → `任务历史`。

- 按"任务类型"和"状态"筛选任务记录。
- 任务状态包括：排队中、运行中、成功、失败、跳过、已取消。
- 运行中或排队中的任务可以取消。
- 已结束的任务记录可以删除，删除记录不会撤销已经写入文件的修改。

进入任务详情后可在"成功"、"失败"、"跳过"标签页查看每首歌的处理结果。即使任务整体显示"成功"，仍可能有单首歌曲失败或跳过。
