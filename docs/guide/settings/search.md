# 在线搜索

进入路径：**设置 → 在线搜索**

## 搜索来源

### 插件管理

导入、启用、停用、排序、配置或卸载搜索源插件，详细操作见 [使用插件](../plugins.md)

### 搜索源标签样式

选择结果页来源标签的显示方式：仅图标、仅文本或图标和文本

## 结果展示

### 单次加载数量

设置每个来源每次加载的候选数量，结果列表底部的“加载更多”可继续获取候选

数量较大时，每次获取的结果更多，也会增加网络请求和图片缓存

<a id="显示全部字段"></a>

### 显示空值字段

开启后，结果详情中值为空的字段显示为“（空）”，关闭时只显示有内容的字段
