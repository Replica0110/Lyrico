# 音乐库管理

进入路径：**设置 → 音乐库管理**

## 文件扫描

### 音频文件夹

添加、刷新、隐藏或移除需要扫描的音频文件夹，详细操作见 [文件夹管理](../library.md#文件夹管理)

移除文件夹会清除对应的音乐库记录，隐藏文件夹则保留记录，两者都不会删除音频文件

### 不扫描 60 秒以下音频

开启后，扫描时跳过短音频，适合排除提示音或短片段

### 歌词索引

扫描时建立歌词搜索索引，让本地搜索能够匹配歌词内容，开启后会增加扫描工作量，已有歌曲需要重新扫描才能补充索引

## 艺术家管理

### 艺术家拆分规则

进入 **设置 → 音乐库管理 → 艺术家拆分规则**，总开关控制是否按多个艺术家归类歌曲

- 列表中的内置和自定义分隔符均会生效，可通过删除停用
- 自定义分隔符和不拆分艺术家名称可点击编辑，通过删除按钮移除
- 删除内置分隔符会停止使用该规则，“恢复默认”会恢复内置分隔符并移除自定义分隔符

修改规则后，可点击 **重建艺术家索引** 更新归类，若艺术家和专辑关联都需要重建，可使用 [重建音乐库索引](./diagnostics.md#重建音乐库索引)

### 艺术家海报文件夹

设置用于读取和保存艺术家海报的文件夹，文件夹选择、命名规则和文件操作见 [艺术家海报](../library.md#艺术家海报)

## 歌曲播放

### 默认播放器

选择播放歌曲时使用的播放器，列表来自设备上可处理音频播放的应用

更换或移除播放器后，返回此页面会刷新显示，已保存的播放器不可用时可以重新选择
