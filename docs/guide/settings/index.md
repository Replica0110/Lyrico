# 设置概览

## 应用设置

| 页面 | 页内分组 | 说明 |
| --- | --- | --- |
| [外观设置](./appearance.md) | 基本设置、主题配色、界面效果 | 界面风格、语言、主题和导航栏效果 |
| [音乐库管理](./library.md) | 文件扫描、艺术家管理、歌曲播放 | 音频文件夹、歌词索引、艺术家规则、海报文件夹和默认播放器 |
| [在线搜索](./search.md) | 搜索来源、结果展示 | 插件管理、来源标签样式、加载数量和空值字段 |
| [标签编辑](./editing.md) | 标签写入、歌词内容、文本处理、回放增益 | 编辑字段、歌词格式、内容顺序、文本清理和响度分析参数 |
| [数据管理](./data.md) | 配置备份、缓存管理 | 导出设置、导入设置和清理缓存 |

## 工具

- [任务历史](./maintenance.md#任务历史)：查看批量任务、筛选执行结果和管理记录
- [问题排查](./diagnostics.md)：应用日志、问题诊断、重建音乐库索引和重置音乐库

## 常用入口

| 需求 | 入口 |
| --- | --- |
| 添加音频文件夹 | 设置 → 音乐库管理 → 音频文件夹 |
| 配置艺术家拆分 | 设置 → 音乐库管理 → 艺术家拆分规则 |
| 管理艺术家海报 | 设置 → 音乐库管理 → 艺术家海报文件夹 |
| 安装和配置插件 | 设置 → 在线搜索 → 插件管理 |
| 调整编辑字段 | 设置 → 标签编辑 → 编辑字段 |
| 调整歌词输出顺序 | 设置 → 标签编辑 → 歌词内容顺序 |
| 配置非歌词内容过滤 | 设置 → 标签编辑 → 非歌词内容过滤规则 |
| 调整回放增益参数 | 设置 → 标签编辑 → 回放增益 |
| 导入或导出配置 | 设置 → 数据管理 → 导入设置 / 导出设置 |
| 记录问题过程 | 设置 → 问题排查 → 问题诊断 |
| 修复艺术家、专辑关联 | 设置 → 问题排查 → 重建音乐库索引 |
