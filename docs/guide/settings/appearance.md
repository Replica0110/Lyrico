# 外观设置

进入路径：**设置 → 外观设置**

## 基本设置

### 界面风格

可选择 **Miuix** 或 **SaltUI**，切换后立即生效

### 应用语言

支持跟随系统、English、简体中文、繁體中文（台灣）和繁體中文（香港）

语言设置只影响应用界面，不会转换歌曲标签内容

## 主题配色

### 主题模式

选择跟随系统、浅色模式或深色模式

<a id="莫奈取色"></a>

### 莫奈配色

开启后，根据所选主题色生成应用配色

### 主题色

开启莫奈配色后可以选择预设颜色，选择壁纸取色选项时使用系统壁纸颜色

## 界面效果

此分组仅在 Miuix 下显示

<a id="模糊"></a>

### 导航栏模糊

启用顶栏和底栏的背景模糊效果

### 悬浮导航栏

在手机端使用悬浮式底部导航栏，不改变各标签页的功能

### 悬浮导航栏效果

开启悬浮导航栏后可选择无、毛玻璃或液态玻璃
