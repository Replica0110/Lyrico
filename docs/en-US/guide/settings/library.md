# Library management

Open **Settings → Library management**.

## File scanning

### Audio folders

Add, refresh, hide or remove scanned folders. See [Folder Management](../library.md#folder-management) for the full workflow.

Removing a folder removes its library records. Hiding it preserves the records. Neither action deletes audio files.

### Ignore audio shorter than 60 seconds

Skip short audio during scanning, for example notification sounds and short clips.

### Lyrics indexing

Build lyric search data while scanning so local search can match lyric content. This adds scanning work. Rescan existing songs to populate the index.

## Artist management

### Artist split rules

Open **Settings → Library management → Artist Split Rules**. The main switch controls whether multi-artist songs are grouped under separate artists.

- Listed built-in and custom separators are active. Remove a separator to stop using it.
- Tap custom separators or no-split artist names to edit them. Use their delete actions to remove them.
- Removing a built-in separator disables that rule. Resetting separators restores built-ins and removes custom separators.

After editing rules, use **Rebuild Artist Index**. To rebuild album associations as well, use [Rebuild library indexes](./diagnostics.md#rebuild-library-indexes).

### Artist poster folder

Choose the folder used to read and save artist posters. See [Artist Posters](../library.md#artist-posters) for selection, naming and file operations.

## Song playback

### Default player

Choose an installed app that can play audio. Returning to this page refreshes the saved player label. If the saved player is unavailable, choose another one.
