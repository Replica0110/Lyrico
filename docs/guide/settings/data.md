# 数据管理

进入路径：**设置 → 数据管理**

## 配置备份

### 导出设置

将当前应用配置导出为 JSON 文件。包含的内容：

- 界面风格（Miuix / SaltUI）
- 主题模式、莫奈配色、主题色、导航栏模糊、悬浮导航栏及其效果
- 搜索设置（插件启用状态、排序、配置、搜索限制等）
- 歌词设置（歌词格式、音译、翻译、歌词内容顺序）
- 目标响度和峰值类型
- 艺术家拆分规则
- 编辑字段配置
- 批量匹配配置

**不包含的内容：**
- 音乐文件本身
- 歌词和封面数据
- 音乐库数据库
- 已安装的插件文件

### 导入设置

从之前导出的 JSON 文件恢复应用配置。导入后，界面风格、主题等外观设置会立即生效。

部分与索引相关的设置（如艺术家拆分规则）可能需要刷新音乐库或重建艺术家索引才能完全体现。

::: warning
配置备份不是完整数据备份。它只包含应用设置，不能用于恢复音乐文件、歌词数据或数据库。
:::

## 缓存管理

### 清理缓存

打开 **清理缓存**，检查分类大小和总量后确认清理

清理内容包括图片缓存、网络缓存、外部缓存及其他临时文件，不删除音频文件，也不清除已写入文件的标签

如果需要修复艺术家或专辑关联，使用 [重建音乐库索引](./diagnostics.md#重建音乐库索引)，清理缓存不会重建音乐库
