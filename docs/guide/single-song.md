# 单曲编辑

单曲编辑页是 Lyrico 的核心界面，用于查看和修改单首歌曲的所有元数据。

## 进入编辑页

有多种方式进入编辑页：

- 在"歌曲"列表、艺术家详情、专辑详情或本地搜索结果中 **点击任意歌曲**。
- 从其他应用（如文件管理器）**打开或分享音频文件到 Lyrico**，会直接进入编辑页。

::: warning 点击不是播放
点击歌曲的默认行为是编辑标签，不是播放。要播放歌曲，请使用更多菜单或编辑页悬浮操作菜单中的“播放音乐”。
:::

## 编辑页布局

编辑页包含以下区域，字段的顺序和显隐可在“编辑字段”中调整：

| 区域 | 功能 |
|------|------|
| 顶部操作栏 | 返回、保存（右上角 ✓） |
| 悬浮操作菜单 | 搜索歌曲信息、歌词、封面，以及播放等操作 |
| 封面区 | 显示/更换/搜索/移除封面与艺术家海报 |
| 标签编辑区 | 标题、艺术家、专辑、专辑艺术家、年份、流派、音轨号、碟号、作曲、作词、注释等字段 |
| 歌词区 | 查看/导入/导出歌词、转换歌词格式、歌词整理、简繁转换、时间轴偏移 |
| 回放增益区 | 计算曲目增益、曲目峰值和参考响度 |
| 自定义标签区 | 管理自定义标签（需要先在设置中添加可见的自定义标签 key） |

如果编辑页缺少某些字段，请检查 **设置 → 标签编辑 → 编辑字段**。关闭字段显示不会清空文件中的数据。见 [编辑字段](./settings/editing.md#编辑字段)。

## 编辑标签并保存

**操作流程：**

1. 进入编辑页，修改需要更改的字段。字段为空时可以直接输入；已有内容的字段可以编辑或清除。
2. 点击右上角的 **✓** 按钮。
3. 保存成功会提示"保存成功"并返回上一页；保存失败会显示失败原因。

**重要提示：**
- 搜索结果、封面选择、歌词处理和回放增益计算都只会先更新编辑页中的临时内容。
- 只有点击右上角的 **✓** 按钮后，所有修改才会写入音频文件。
- 部分 Android 版本或特定目录可能弹出额外的授权请求，按提示操作即可。

## 搜索歌词和元数据

通过插件搜索在线歌曲信息，用于补全标题、艺术家、歌词等字段。

**操作流程：**

1. 在编辑页展开悬浮搜索按钮，选择 **“主搜索”**。搜索页使用当前标题和艺术家作为关键词；没有标题时使用文件名。
2. 在搜索页调整关键词并搜索。只需歌词或封面时，可选择 **“搜索歌词”** 或 **“搜索封面”**；这两个入口也分别位于歌词选项和封面选项中。入口仅在有对应能力的已启用插件时显示。
3. 搜索结果页按"全部"和各插件源分标签显示。
   - 点击结果列表底部的“加载更多”按钮可加载下一页；“全部”标签会继续加载所有尚有下一页的插件源。
4. 点击某个搜索结果，进入结果详情页，可以查看搜索到的元数据和歌词。
   - 默认只显示搜索源返回了内容的字段。可在 `设置` → `在线搜索` 中开启"显示空值字段"；空字段会显示为"（空）"。
5. 在结果详情页选择操作：
   - **"应用"**：将勾选的元数据和歌词一起应用到当前编辑页。
   - **"仅歌词"**：只应用歌词内容到编辑页。
6. 回到编辑页，检查内容无误后点击右上角的 **✓** 按钮。

::: tip 搜索结果为空？
检查 `设置` → `在线搜索` → `插件管理` 中是否安装并启用了至少一个支持歌曲搜索的插件，以及插件配置是否填写完整。详见 [使用插件](./plugins.md)。
:::

## 封面操作

点击编辑页中的封面区域或"封面选项"，可以执行以下操作：

| 操作 | 说明 |
|------|------|
| 搜索封面 | 通过已启用的封面搜索插件查找图片 |
| 从本地选择封面 | 从系统图片选择器选择本地图片 |
| 从同专辑选择封面 | 直接使用同专辑中找到的第一张可读封面 |
| 移除封面 | 删除当前歌曲的封面 |
| 保存封面 | 将当前封面保存到指定位置或音频同目录 |
| 裁剪封面 | 裁剪当前封面后再应用 |

网络封面搜索需要已安装并启用支持封面搜索的插件。结果页底部可点击“加载更多”；“全部”标签会继续加载所有尚有下一页的封面源。

## 艺术家海报操作

封面区可以左右切换到艺术家海报。艺术家字段里有几位艺术家，就有几个海报位，一位艺术家一张海报。

一张图属于谁，看它的**图片描述**：描述写的是哪位艺术家，这张图就归谁。没写描述的旧图片，仅当整首歌只有一位艺术家时才归给这位艺术家；描述对不上任何艺术家时，这张图会单独占一页（标签是琥珀色），表示它还没有归属。

点击当前这一页的海报，或从悬浮菜单打开 **“艺术家海报选项”**，可以执行：

| 操作 | 说明 |
|------|------|
| 从本地选择艺术家海报 | 从系统图片选择器选择本地图片，写入当前歌曲的内嵌海报。多艺术家时先选归属；该艺术家原有的海报会被替换。艺术家字段为空时会提示先填写 |
| 移除艺术家海报 | 删除当前这张内嵌海报。只改这首歌的标签，其他歌曲和海报文件夹里的文件都不受影响；点右上角的 **✓** 按钮后才写入文件 |
| 保存艺术家海报 | 将当前这张海报导出到系统图片目录 |
| 裁剪艺术家海报 | 裁剪当前这张海报后再应用 |
| 重新选择“…”对应的艺术家 | 改挂当前这张海报的归属。目标艺术家已有海报时，可选 **“交换归属”**（两张都留着，互换所属艺术家）或 **“直接替换”**（删除原有海报） |

**“移除艺术家海报”**、**“保存艺术家海报”**、**“裁剪艺术家海报”** 只对内嵌海报有效；当前页只有海报文件夹里的外置海报时，这三项不出现。如果要去掉这位艺术家在所有歌曲里的内嵌海报，并删除海报文件夹里对应的文件，需要在艺术家列表或详情页操作，见 [艺术家海报](./browsing.md#艺术家海报)。

没有内嵌海报的艺术家，会去 [艺术家海报](./library.md#艺术家海报) 文件夹里按文件名找（例如 `周杰伦.jpg`），一位艺术家一个文件。外置海报只用于显示，不会写入歌曲。当前这一页的左下角会显示图片尺寸和来源：**内嵌** 或 **外部文件**。

编辑页里从本地选择的海报总是写入当前歌曲的内嵌海报，点右上角的 **✓** 按钮后随歌曲文件保存。想按艺术家名存进海报文件夹、不改动歌曲文件，去艺术家详情页的 **“艺术家海报选项” → “从本地选择艺术家海报”**，在 **“海报保存位置”** 里选 **“从本地添加海报到文件夹”**。两种保存位置的完整说明见 [艺术家海报](./browsing.md#艺术家海报)。

查看海报大图（双指缩放、拖动平移、左右翻页、图片信息）在艺术家列表或详情页，见 [大图预览](./browsing.md#大图预览)。MP4 海报可以在艺术家列表或详情页直接播放；视频海报不能裁剪。

::: warning MP4、M4A 等格式
MP4、M4A 格式不能保留图片类型和图片描述，编辑页里只有封面，没有艺术家海报位。在艺术家列表或详情页给这位艺术家写入内嵌海报时，MP4、M4A 歌曲会被跳过；结果会分别显示已嵌入、跳过不支持的格式和失败的数量。
:::

::: tip 描述对不上了？
改过艺术家字段之后，旧海报的描述可能就对不上任何人。描述对不上艺术家的海报仍会列在编辑页里，菜单里的 **“重新选择‘…’对应的艺术家”** 可以改挂到正确的艺术家。
:::

## 歌词操作

在编辑页打开 **“歌词选项”**：

| 操作 | 说明 |
|------|------|
| 搜索歌词 | 通过已启用的歌词搜索插件查找歌词 |
| 导入 | 从文本文件读取歌词，按 UTF-8 文本处理 |
| 导出 | 将当前歌词保存到指定文件夹或音频同目录。TTML 导出为 `.ttml`，其他导出为 `.lrc`；空歌词不会导出 |
| 简繁转换 | 将当前歌词在简体中文和繁体中文之间转换 |
| 歌词偏移 | 按 100 毫秒步进调整，或点击数值 / 手动输入设置偏移；支持重置为 `0` |
| 转换歌词格式 | 转为其他歌词格式 |
| 歌词整理 | 调整行顺序、删除空行或删除作词作曲等信息 |
| 查看歌词文本 | 把逐字歌词等内容转成普通文本查看，可切换显示音译和翻译 |

歌词偏移以毫秒为单位，每次增减 100 毫秒；点击当前数值或“手动输入”可输入 -10,000 到 10,000 毫秒的整数。正值表示整体后移，负值表示整体提前，点击“重置”恢复为 `0`。

### 转换歌词格式

选择 **歌词选项 → 转换歌词格式**，选择目标格式并确认，最后点击右上角的 **✓** 按钮。

没有逐字时间信息的歌词，不能通过转换生成逐字时间轴。

### 歌词整理

打开 **歌词选项 → 歌词整理**，选择一项操作：

- **按句排序**：调整同一时间点多行歌词的顺序，或移除其中一行。分别设置 2 行和 3 行歌词的排列方式。
- **移除空行**：删除空白或仅含占位符的歌词行。
- **移除非歌词内容**：按 [过滤规则](./settings/editing.md#非歌词内容过滤规则) 删除作词、作曲等信息。

例如，同一时间点第 1 行是原文、第 2 行是翻译。想让翻译显示在前，就将“原第 2 行”设为“保留为第 1 行”。行号只表示当前顺序，不会自动识别原文、翻译或音译。

按句排序支持 LRC，并保留逐字时间信息；TTML 和只有一行的时间点不作调整。处理后点击右上角的 **✓** 按钮，修改才会写入文件。

## ReplayGain

ReplayGain（回放增益）用于统一不同歌曲的播放音量。

**操作流程：**

1. 在编辑页找到 **“回放增益”** 分组。
2. 点击 **“计算回放增益”**，Lyrico 开始分析当前音频。
3. 计算中会显示进度百分比；再点一次按钮会中止扫描。
4. 计算完成后，曲目增益、曲目峰值和参考响度等字段会填入编辑页。已有 ReplayGain 值的歌曲可以重新计算覆盖。
5. 点击右上角的 **✓** 按钮，将曲目增益、曲目峰值和参考响度写入音频文件。

计算使用的目标响度和峰值测量方式来自 `设置` → `标签编辑` → `回放增益`。参考响度默认为 -18 LUFS；峰值默认使用采样峰值，也可切换为真实峰值。修改后需要重新计算才会影响填入的标签值。

分析音频时优先使用 Android 平台的解码器。平台解码失败时，Lyrico 会用内置的 FFmpeg 再解码一次，FFmpeg 后备解码只覆盖 **ALAC** 和 **APE**。解码出的内容只用于测量响度：Lyrico 仍然不是播放器，后备解码也不代表支持 FFmpeg 的其他格式。ALAC 或 APE 文件损坏时，计算同样会失败。

计算失败时会提示原因，例如未找到有效音轨、无法识别音频编码、设备不支持解码。

## 更多菜单

编辑页的更多菜单包含：

- **歌曲信息**：查看详细文件信息（时长、比特率、采样率、声道、路径、文件大小等），可复制内容。
- **分享歌曲**：通过系统分享面板发送音频文件。
- **重命名文件**：修改文件名，保留原扩展名（不会修改标题标签）。
- **删除歌曲**：删除本地音频文件，不可撤销。
